#AfriTalent 
Projet fil rouge - Plateforme de mise en relation entre freelances africains et clients.

Description du projet
AfriTalent est un site réalisé dans le cadre d'un projet scolaire.il a été conçu pour présenter un site moderne avec une interface claire et responsive.Le projet permet de mettre en pratique les compétences en HTML, CSS, et en Javascript.

Fonctionnalités
site responsive(mobile,tablette,desktop)
Mode clair/mode sombre
Navigation entre les sections
Formulaire de contact avec validation Javascript
Interface simple et moderne

Technologies utilisées
HTML5
CSS
JavaScript
